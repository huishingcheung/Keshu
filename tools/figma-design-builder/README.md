# JNU Smart Edu Design Builder

This local Figma development plugin builds the JNU Smart Edu design system and app screens without using Figma MCP calls.

## Import

1. Open the target file in the Figma desktop app.
2. Open `Plugins > Development > Import plugin from manifest`.
3. Select `manifest.json` in this directory.
4. Run `JNU Smart Edu Design Builder` from `Plugins > Development`.
5. Run the four phases in order.

The plugin only replaces nodes tagged with the `jnu.smartedu.designbuilder` shared-plugin namespace. Existing frames are preserved.

If Figma rejects the development plugin ID, create a new `Custom UI` development plugin, keep the ID generated by Figma, and point its `main` and `ui` fields to the files in this directory.
